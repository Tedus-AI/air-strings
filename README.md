# Air Strings 空中弦

用雙手在空中拉出會發聲的弦，再用手指撥它。純網頁，不用安裝任何軟體。

**線上使用：** https://tedus-ai.github.io/air-strings/

## 怎麼玩

| 動作 | 做法 |
|---|---|
| 拉弦 | 雙手都用拇指捏住食指，往兩邊拉開再放開，弦就留在空中。單手捏住拖曳也可以。 |
| 撥弦 | 張開手，用食指或中指劃過弦。劃得越快聲音越大；撥在兩端聲音較亮，撥在中間較圓。 |
| 調整 | 捏住弦的端點拖動改長短；捏住弦的中段整條搬動（觸控：按住端點／在弦上長按）。 |
| 顫音 | 撥完後手掌上下快速抖動。 |
| 制音 | 握拳，所有正在響的弦立刻停下。 |
| 一鍵樂器 | 工具列「🎼 樂器」：豎琴、吉他（和弦）、扇形，依目前音階自動排好，可復原。 |
| 隔空按鈕 | 手指（拇指與食指之間的點）移到工具列、遊戲選單或對話框的按鈕上：捏一下＝按下，停住約 1 秒＝自動按下。下拉選單會改成一排大按鈕；工具列放不下時，指標停在左右邊緣會自動捲動。 |
| 多人 | 最多同時追蹤 4 隻手，每隻手骨架顏色不同。 |
| 連線 | 連續撥不同的弦，弦之間會出現漸漸消失的光弧。 |
| 刪除 | 點一下弦，按「✕ 刪除這條弦」；或用 ↶ 復原、「清空」。 |

沒有鏡頭時，可以按「只用觸控試玩」：在空白處拖曳拉出弦、劃過弦撥弦、按住端點拖動調整。前鏡頭會自動鏡像。

## 遊戲類

工具列「🎮 遊戲類」打開遊戲選單。開始遊戲時會暫時收起你的弦，結束後自動還原。

- **⚽ 守護球**：球依重力落下，拉弦把它彈回去，不能讓它掉到底（3 條命）。單手捏住拖一段放開即可拉弦，雙手也可以。
  - 弦被視為有張力的彈簧：音越高（越緊）越硬越彈；打在弦兩端比正中間硬；只有沿弦法線的力，所以入射角＝反射角。
  - 被球碰過的弦會出現裂痕並標示「剩 N」；碰到耐久次數就斷。耐久＝2 × 球數（1 顆球 2 次、2 顆 4 次、3 顆 6 次…）。
  - 每斷 5 條弦升一級，速度 ×1.0 → ×1.2 → ×1.4 → ×1.6 …（每級 +0.2）；每升 2 級自動多一顆球（球與球之間也會彈性碰撞）。
  - 漏接一顆球扣一條命，該顆球重新從上方出場；3 條命用完結束。
- **⚔️ 守護球對戰**（雙人）：以螢幕中線為界，左右各一位玩家，各自只有一條弦，兩端永遠限制在自己半場。
  - 雙手捏住自己弦的兩端可拉長、縮短、移動；捏住中段可整條帶著跑（觸控：按住端點或中段拖動）。
  - 弦是會動的彈簧：接觸力取決於球與弦的相對速度，揮弦迎擊時弦的速度會加到球上；弦橫掃過球時以相對速度反射，不會穿過。
  - 球掉到誰的半場底部誰失分，發球給失分方；先得 7 分獲勝。
- **🔨 音樂打地鼠**：握拳＝拿起槌子（拳頭就是槌頭），舉起往下劈再停住＝敲一下；觸控直接點。
  - 每個洞固定一個五聲音階的音（前排低、後排高），敲中就彈出那個音；連擊 6 以上會加上五度和聲。
  - 自由演奏 60 秒：普通 +10、金色快閃 +50、戴鋼盔要敲兩下、兔子不能敲（-20）。20 秒後同時 2 隻，最後 15 秒狂熱（3 隻、分數 ×2）；連擊倍率 ×1.5／×2／×3。
  - 歌曲模式：地鼠依旋律順序冒出來，全部敲中就彈完整首歌。
  - 判定：掌心位置平滑後偵測「往下速度超過門檻 → 急停」才算一槌，慢慢放下手不會誤觸；門檻依玩家力道自動校正；命中範圍放大且地鼠縮回後 0.12 秒內仍算（補償鏡頭延遲）。開局先有一隻練習地鼠。
- **🎵 跟彈歌曲**：自動排好一把豎琴，依序撥亮起的弦（小星星、小蜜蜂、歡樂頌、生日快樂）。

遊戲進行中會收起下方工具列（整個畫面都給遊戲），並停用「停住自動點擊」，手在畫面上移動不會誤按。要離開或調整時按上方「⏸ 暫停」（隔空：捏住 0.6 秒；觸控：點一下；鍵盤：Esc），暫停畫面可繼續、重新開始、換遊戲或離開，工具列也會回來。

新增遊戲：在 `GAMES` 加一個物件（`start / update / draw / onPluck / hud / hint`），並在 `#gameMenu` 加一個 `data-game` 按鈕。

## 建議裝置

- iPad / iPhone：用 Safari 打開，前鏡頭即可。iPad 立起來放、人離約 50～80 cm 效果最好。
- 電腦：需要網路攝影機，建議用 Chrome 或 Edge。

## 技術

- 手部追蹤：[MediaPipe Hand Landmarker](https://ai.google.dev/edge/mediapipe/solutions/vision/hand_landmarker)，在瀏覽器端執行，畫面不會上傳。
- 聲音：Web Audio，以 Karplus-Strong 演算法即時合成撥弦聲，含撥弦位置與音色參數。
- 部署：推到 `main` 後由 GitHub Actions 自動發布到 GitHub Pages，並自動蓋上版本號。

## 已知限制

- 光線太暗或背景很雜時，手部追蹤會不穩。
- 第一次開啟需要下載約 8 MB 的手部模型，之後會被瀏覽器快取。
